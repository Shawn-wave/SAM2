# SAM2 Interactive Segmentation

This repository provides interactive segmentation tools using Meta's Segment Anything Model 2 (SAM2) for both images and videos. The tools allow you to segment objects by simply clicking on them.

## Features

- **Interactive Image Segmentation**: Click-based segmentation for static images
- **Interactive Video Segmentation**: Propagate segmentation across video frames
- **Multiple Output Formats**: PNG, JPG, and NumPy arrays
- **User-Friendly Interface**: Simple mouse interactions
- **Batch Processing**: Segment multiple objects in sequence

## Usage

### Image Segmentation

1. **Configure paths** in `image.py`:
```python
IMAGE_PATH = "./file/your_image.jpg"     # Input image path
SAM_PATH = "./segment-anything-2"        # SAM2 directory
CHECKPOINT = "sam2_hiera_large.pt"       # Checkpoint filename
OUTPUT_BASE_DIR = "./output"             # Output directory
```

2. **Run the script**:
```bash
python image.py
```

3. **Interactive segmentation**:
   - Enter a label name for the object
   - **Left click**: Select positive points (areas to include)
   - **Right click**: Select negative points (areas to exclude)
   - Press any key to finish point selection
   - Type 'exit' when done with all objects

### Video Segmentation

1. **Configure paths** in `video.py`:
```python
VIDEO_PATH = "./data/your_video.mp4"     # Input video path
SAM_PATH = "./segment-anything-2"        # SAM2 directory
CHECKPOINT = "sam2_hiera_large.pt"       # Checkpoint filename
OUTPUT_BASE_DIR = "./output"             # Output directory
```

2. **Run the script**:
```bash
python video.py
```

3. **Interactive segmentation**:
   - Enter a label name for the object
   - Click on the first frame to select the object
   - **Left click**: Positive points (include)
   - **Right click**: Negative points (exclude)
   - Press any key to finish point selection
   - The segmentation will propagate to all frames automatically

## Output Files

### Image Segmentation Outputs

For each segmented object, the following files are generated:

| File Type | Description | Use Case |
|-----------|-------------|----------|
| `mask_0_object.png` | Binary mask (black/white) | General masking applications |
| `mask_0_object.npy` | Boolean mask (numpy array) | Programming/analysis |
| `masked_original_0_object.jpg` | Object only (black background) | Background removal |
| `masked_original_0_object.npy` | Object only (numpy array) | Programming/analysis |
| `overlay_0_object.jpg` | Original + colored overlay | Verification |

### Final Combined Results

| File Type | Description |
|-----------|-------------|
| `final_segmentation.jpg` | All objects with different colors |
| `combined_masks.png` | All objects in one mask (different values) |

## Working with NumPy Files (Machine Learning)


The NumPy files generated by SAM2 can be used to create a complete machine learning pipeline for custom object detection and segmentation. Here's the typical workflow:

### Pipeline Overview

```
📸 Data Collection → 🎯 SAM2 Labeling → 🔄 Format Conversion → 🤖 Model Training → 🚀 Real-time Deployment
```

1. **Data Collection**: Gather images/videos of your target objects
2. **SAM2 Labeling**: Use `image.py` and `video.py` to create high-quality masks
3. **Format Conversion**: Convert NumPy masks to ML training formats (YOLO, PyTorch, etc.)
4. **Model Training**: Train custom object detection/segmentation models
5. **Real-time Deployment**: Deploy trained models for real-time inference

### Converting to Training Data

The NumPy masks generated by SAM2 can be converted into training datasets for machine learning models:

#### Convert to YOLO Format
```python
def get_bbox_from_mask(mask):
    """Convert boolean mask to bounding box coordinates"""
    coords = np.column_stack(np.where(mask))
    if len(coords) == 0:
        return None
    y1, x1 = coords.min(axis=0)
    y2, x2 = coords.max(axis=0)
    return [x1, y1, x2, y2]  # [xmin, ymin, xmax, ymax]

def mask_to_yolo_format(mask, image_width, image_height, class_id):
    """Convert mask to YOLO annotation format"""
    bbox = get_bbox_from_mask(mask)
    if bbox is None:
        return None
    
    x1, y1, x2, y2 = bbox
    
    # Convert to YOLO format (normalized center coordinates + width/height)
    center_x = (x1 + x2) / 2 / image_width
    center_y = (y1 + y2) / 2 / image_height
    width = (x2 - x1) / image_width
    height = (y2 - y1) / image_height
    
    return f"{class_id} {center_x:.6f} {center_y:.6f} {width:.6f} {height:.6f}"

# Example: Create YOLO dataset
class_mapping = {'person': 0, 'car': 1, 'bike': 2}

for output_dir in glob.glob('./output/output_*/'):
    image = Image.open(f'{output_dir}/original.jpg')
    w, h = image.size
    
    annotations = []
    for mask_file in glob.glob(f'{output_dir}/mask_*.npy'):
        # Extract label from filename: mask_0_person.npy -> person
        label = mask_file.split('_')[2].split('.')[0]
        class_id = class_mapping.get(label, 0)
        
        mask = np.load(mask_file)
        yolo_annotation = mask_to_yolo_format(mask, w, h, class_id)
        if yolo_annotation:
            annotations.append(yolo_annotation)
    
    # Save YOLO annotation file
    with open(f'{output_dir}/annotations.txt', 'w') as f:
        f.write('\n'.join(annotations))
```

#### Create PyTorch Dataset
```python
import torch
from torch.utils.data import Dataset
from torchvision import transforms

class SAM2Dataset(Dataset):
    def __init__(self, output_dirs, transform=None):
        self.data = []
        self.transform = transform
        self.class_to_idx = {}
        
        # Load all SAM2 outputs
        for output_dir in output_dirs:
            self._load_sam2_output(output_dir)
    
    def _load_sam2_output(self, output_dir):
        image_path = f'{output_dir}/original.jpg'
        image = Image.open(image_path)
        
        # Load all masks for this image
        for mask_file in glob.glob(f'{output_dir}/mask_*.npy'):
            label = mask_file.split('_')[2].split('.')[0]
            
            # Create class mapping
            if label not in self.class_to_idx:
                self.class_to_idx[label] = len(self.class_to_idx)
            
            mask = np.load(mask_file)
            
            self.data.append({
                'image': image,
                'mask': mask,
                'label': label,
                'class_idx': self.class_to_idx[label]
            })
    
    def __len__(self):
        return len(self.data)
    
    def __getitem__(self, idx):
        item = self.data[idx]
        image = item['image']
        mask = item['mask']
        
        if self.transform:
            image = self.transform(image)
        
        return {
            'image': image,
            'mask': torch.tensor(mask, dtype=torch.bool),
            'label': item['class_idx']
        }

# Usage example
dataset = SAM2Dataset(['./output/output_image1', './output/output_image2'])
dataloader = torch.utils.data.DataLoader(dataset, batch_size=4, shuffle=True)
```

### Real-time Inference Pipeline

Once you have trained a model using SAM2-generated data, you can create a real-time inference system:

```python
import cv2
from ultralytics import YOLO

# Load model trained on SAM2 data
model = YOLO('path/to/your/trained/model.pt')

def real_time_detection():
    cap = cv2.VideoCapture(0)
    
    while True:
        ret, frame = cap.read()
        if not ret:
            break
        
        # Run inference
        results = model(frame)
        
        # Draw results
        for r in results:
            boxes = r.boxes
            if boxes is not None:
                for box in boxes:
                    if box.conf > 0.5:  # Confidence threshold
                        x1, y1, x2, y2 = box.xyxy[0]
                        class_id = int(box.cls[0])
                        conf = box.conf[0]
                        
                        # Draw bounding box
                        cv2.rectangle(frame, (int(x1), int(y1)), (int(x2), int(y2)), (0, 255, 0), 2)
                        cv2.putText(frame, f'Class {class_id}: {conf:.2f}', 
                                  (int(x1), int(y1-10)), cv2.FONT_HERSHEY_SIMPLEX, 0.5, (0, 255, 0), 2)
        
        cv2.imshow('Real-time Detection', frame)
        if cv2.waitKey(1) & 0xFF == ord('q'):
            break
    
    cap.release()
    cv2.destroyAllWindows()

# Run real-time detection
real_time_detection()
```

## Troubleshooting

### Common Issues

1. **CUDA out of memory**: Reduce image/video resolution
2. **Checkpoint not found**: Ensure the checkpoint file is downloaded correctly
3. **OpenCV window not responding**: Make sure you have a display available
4. **Import errors**: Verify all dependencies are installed

### Performance Tips

- Use GPU if available (CUDA)
- Reduce input resolution for faster processing
- Use fewer points for initial segmentation, add more if needed
- For videos, segment on a representative frame

## System Requirements

- **GPU**: NVIDIA GPU with CUDA support (recommended)
- **RAM**: 8GB+ (16GB+ for large videos)
- **Python**: 3.8+
